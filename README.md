# Custosell Backend (ERP + POS System)

Custosell Backend is the **API-first Laravel application** powering the **Custosell ERP and POS system**.  
It provides core functionalities for managing products, inventory, sales, customers, suppliers, payments, and reporting.  
This backend is designed to integrate seamlessly with a modern frontend (e.g., React, Vue, or mobile app).

---

## 🚀 Features
- **API-Only Backend** (Laravel 11+, with `php artisan install:api`)
- **Authentication & Authorization** (Laravel Sanctum or Passport)
- **User & Role Management** (Admin, Cashier, Manager, etc.)
- **Product & Inventory Management**
- **Sales & POS Transactions**
- **Supplier & Customer Management**
- **Payments & Multi-method Support (cash, card, mobile money)**
- **Branch / Multi-store Support**
- **Reporting & Analytics APIs**
- **Extensible Architecture** (future modules: HR, Accounting, CRM, etc.)
