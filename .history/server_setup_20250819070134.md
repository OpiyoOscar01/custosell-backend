# Server Setup Guide for Your Laravel API

Based on our testing, we've confirmed that your API routes are working correctly within the application. However, there are some connectivity issues when trying to access them via HTTP. Here are detailed instructions to set up your server properly:

## Option 1: Use XAMPP (Recommended for Windows)

1. **Install XAMPP** if you haven't already:
   - Download from [https://www.apachefriends.org/index.html](https://www.apachefriends.org/index.html)
   - Install with Apache and MySQL at minimum

2. **Configure Virtual Host**:
   - Open `C:\xampp\apache\conf\extra\httpd-vhosts.conf`
   - Add this configuration:
   ```
   <VirtualHost *:80>
       DocumentRoot "C:/xampp/htdocs"
       ServerName localhost
   </VirtualHost>

   <VirtualHost *:80>
       DocumentRoot "C:/Users/Josemiles/Desktop/custosell-backend/public"
       ServerName custosell.test
       <Directory "C:/Users/Josemiles/Desktop/custosell-backend/public">
           Options Indexes FollowSymLinks
           AllowOverride All
           Require all granted
       </Directory>
   </VirtualHost>
   ```

3. **Update Hosts File**:
   - Open Notepad as Administrator
   - Open the file `C:\Windows\System32\drivers\etc\hosts`
   - Add this line: `127.0.0.1 custosell.test`

4. **Restart Apache** in XAMPP Control Panel

5. **Access your API** at:
   - Web interface: `http://custosell.test`
   - API endpoints: `http://custosell.test/api/auth/login` etc.

## Option 3: Disable Firewall Temporarily for Testing

```powershell
# Check firewall status
Get-NetFirewallProfile

# Temporarily disable firewall (be careful with this!)
Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled False

# Remember to turn it back on after testing
Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled True
```

## Test Your API with Postman

1. **Download and install Postman** from [https://www.postman.com/downloads/](https://www.postman.com/downloads/)

2. **Create a new collection** for your API

3. **Set up your requests**:

   **Login Request**:
   - Method: POST
   - URL: `http://custosell.test/api/auth/login` (or whichever server you're using)
   - Headers: 
     - Content-Type: application/json
     - Accept: application/json
   - Body (raw/JSON):
   ```json
   {
       "email": "newtest@example.com",
       "password": "password123"
   }
   ```

   **Register Request**:
   - Method: POST
   - URL: `http://custosell.test/api/auth/register`
   - Headers:
     - Content-Type: application/json
     - Accept: application/json
   - Body (raw/JSON):
   ```json
   {
       "name": "Another User",
       "email": "another@example.com",
       "password": "password123",
       "password_confirmation": "password123"
   }
   ```

   **Logout Request**:
   - Method: POST
   - URL: `http://custosell.test/api/auth/logout`
   - Headers:
     - Content-Type: application/json
     - Accept: application/json
     - Authorization: Bearer {{token}} 
       (Get the token from login response)

Remember to update your `.env` file to match your server configuration:
```
APP_URL=http://custosell.test
```

These solutions should help you overcome the connectivity issues you're experiencing. The script testing we did already confirmed that your routes and controller logic are working correctly.
